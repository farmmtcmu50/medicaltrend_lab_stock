# นำเข้าสินค้าจาก XLSX

1. ในหน้ารายการสินค้า กด **ดาวน์โหลด Template XLSX**
2. กรอกชีต **สินค้า** แถว 2 เป็นต้นไป สูงสุด 200 รายการต่อไฟล์
3. เลือกเครื่องและ Supplier จากทะเบียนที่เปิดใช้งาน (แนบอยู่ใน Template)
4. กด **นำเข้าสินค้าจาก XLSX** แล้วเลือกไฟล์ `.xlsx` ขนาดไม่เกิน 2 MB
5. ตรวจข้อมูลในหน้าตัวอย่าง แก้ไฟล์และนำเข้าใหม่หากมีข้อผิดพลาด
6. กด **ยืนยันบันทึกสินค้า** เพื่อเพิ่มสินค้าใหม่ทั้งชุด

Template มีคำแนะนำและตัวอย่างในชีตแยก จึงไม่เผลอนำเข้าตัวอย่างเป็นสินค้าจริง
ช่องชื่อสินค้า เครื่อง Supplier หน่วยหลัก การใช้หน่วยย่อย Lead Time และ Safety Stock ต้องกรอก
หากใช้หน่วยย่อย ต้องระบุชื่อหน่วยย่อยและจำนวนย่อยต่อหลัก ราคาต้นทุนต่อหน่วยหลักกรอกได้เฉพาะ Admin
สินค้าที่ไม่มีหน่วยย่อยจะใช้หน่วยหลักและอัตราแปลง 1 อัตโนมัติ

ระบบเพิ่มเฉพาะรายการสินค้า ไม่รับยอด Stock และไม่แก้ทับสินค้าเดิม
ชื่อ+เครื่อง+Supplier ซ้ำกับสินค้าเดิมหรือซ้ำภายในไฟล์จะไม่ผ่านการตรวจสอบ
ไม่มีการประมวลผลสูตร Excel และไม่รับ Macro หรือลิงก์ไฟล์ภายนอก

หน้าตรวจสอบมีอายุ 30 นาที ระบบตรวจทะเบียนและรายการซ้ำอีกครั้งขณะยืนยัน
หากข้อมูลเปลี่ยนระหว่างนั้นให้ตรวจไฟล์ใหม่ การบันทึกเป็นธุรกรรมเดียวทั้งชุด
คำขอที่สำเร็จแล้วสามารถส่งซ้ำเพื่อรับผลเดิมได้โดยไม่สร้างสินค้าซ้ำ
