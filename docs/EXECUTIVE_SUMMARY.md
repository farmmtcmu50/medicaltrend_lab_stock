# Executive Summary

เข้าเมนู รายงาน → Executive Summary ด้วยบัญชี admin รายงานมีข้อมูลต้นทุนจึงไม่เปิดให้ staff และไม่ใช้สิทธิ์ Dashboard แทนสิทธิ์รายงาน

เลือกวัน/7 วันล่าสุด/เดือนนี้/ไตรมาสนี้/ปีนี้/วันที่อิสระ สูงสุด 366 วัน และกรองเครื่องหรือ Supplier แล้วกดแสดงรายงาน ตัวกรองเป็นอิสระจาก Dashboard, PR และรายงานเคลื่อนไหว

## ห้าส่วนของรายงาน
- ภาพรวม: มูลค่าปลายงวด การใช้สุทธิ DOH จำนวน/สัดส่วนสินค้าขาดและถึง ROP ใกล้หมดอายุ และตัดทิ้ง พร้อมกราฟตามเครื่องและประเด็นพิจารณา
- เงินจม/ต้นทุน: ต้นงวด–ปลายงวด สินค้าไม่เคลื่อนไหว สินค้าครอบคลุมสูงกว่า 45 วันหรือ 2 เท่าของ Lead Time (ใช้ค่าสูงกว่า) Lot ใกล้หมดอายุ และสาเหตุสูญเสีย
- ความพร้อมให้บริการ: ขาดสต๊อก ถึง ROP ครอบคลุมต่ำกว่า Lead Time สินค้าหมดอายุ และ PR รับไม่ครบ
- จัดซื้อ/Supplier: จำนวนและมูลค่า PR รออนุมัติ ค้างรับ OTIF Lead Time เวลาอนุมัติเฉลี่ย และความครบถ้วนวันที่จัดซื้อ
- สรุปเปิดประชุม: ข้อความสรุปจากตัวเลขจริงตามตัวกรอง คัดลอกไปจัดทำอีเมลหรือเอกสารได้ (ระบบไม่ส่งอีเมลอัตโนมัติ)

คลิกตัวเลข/กราฟ/ประเด็นเพื่อเปิดรายละเอียด ตารางหน้ารายงานแสดง 10 แถวแรก ปุ่มดูทั้งหมดเปิดรายการครบ กดพิมพ์สรุป / Save PDF เพื่อเปิดหน้าสรุปที่จัดรูปแบบ A4 แล้วเลือกพิมพ์หรือ Save PDF ในเบราว์เซอร์

## ความหมายและข้อจำกัด
- ยอดคลังต้นงวด/ปลายงวด รับ ใช้ ตัดทิ้งเป็นงวดที่เลือก แต่สต๊อกคงเหลือ ความเสี่ยงหมดอายุ และ PR ค้างเป็นปัจจุบัน มีวันที่กำกับ
- เปรียบเทียบกับช่วงก่อนหน้า **จำนวนวันเท่ากัน** ไม่ใช่ทั้งเดือนก่อน เช่น 1–16 พ.ย. เทียบ 16–31 ต.ค.
- มูลค่าคำนวณจากราคาต้นทุนปัจจุบัน ไม่ใช่ต้นทุนซื้อจริงแยก Lot มูลค่า PR เป็นยอดขอซื้อ ไม่ใช่ยอดจ่ายจริง
- DOH = มูลค่าปลายงวด ÷ (มูลค่าใช้สุทธิ ÷ จำนวนวัน) ไม่มีการใช้ให้แสดง — ไม่แทนด้วยศูนย์
- อัตราใช้เพื่อประเมินความพร้อมใช้จำนวนหน่วยจริง จึงคำนวณได้แม้ราคาต้นทุนเป็นศูนย์ ระยะครอบคลุมเป็นค่าประมาณ ไม่ใช่พยากรณ์
- สินค้าไม่เคลื่อนไหวหมายถึงไม่มีธุรกรรมในงวด ไม่ใช่ข้อยืนยันว่าไม่มีการใช้ตลอดอายุสินค้า
- FEFO ใช้จำนวน Lot เรียงวันหมดอายุและยอดใช้เฉลี่ยในงวด ถ้าไม่มีการใช้จะไม่เดาวันใช้หมด
- OTIF วัดส่วนของ Supplier ทั้งใบ PR ที่อนุมัติและมีข้อมูลวันออก PO/นัดส่ง โดยออก PO ในงวดและถึงวันนัดแล้ว เครื่องใช้คัดเลือกใบ PR ที่เกี่ยวข้อง ไม่ตัดบางบรรทัดออกจากเกณฑ์รับครบของ Supplier
- Lead Time เฉลี่ยใช้ใบที่รับครบในงวดและมีวันที่ออก PO เวลาอนุมัติใช้ใบที่ขอซื้อในงวดและมีวันอนุมัติไม่ก่อนสร้างใบ
- ฐาน Wastage ใช้มูลค่าซื้อทั้งคลังที่บันทึกไว้สำหรับงวดเดียวกัน หากกรองสินค้า ตัวเศษเป็นส่วนที่กรอง ตัวส่วนยังเป็นทั้งคลัง และถ้าไม่มีฐานจะไม่แสดงเปอร์เซ็นต์
- ยังไม่มีการระบุสินค้าจำเป็นต่อเครื่อง/งาน จึงยังไม่สรุปว่าเครื่องใดจะหยุดบริการ และไม่มีการอนุมัติ PR/ตัดทิ้งอัตโนมัติจากรายงาน

## ตรวจสอบ
มีการทดสอบสูตร สิทธิ์ admin การแยก tenant ตัวกรองไม่ข้ามเมนู จำนวน PR ไม่ซ้ำ การเปรียบเทียบงวด ข้อมูลว่าง สินค้าราคา 0 และการป้องกัน response เก่าทับผลลัพธ์ล่าสุด

## Inventory & Turnover
ส่วน LAB INVENTORY & TURNOVER ANALYTICS ย้ายจาก Dashboard มาอยู่แท็บ Inventory & Turnover ใน Executive Summary รวม KPI มูลค่าคลัง/จำนวนสินค้า/อัตราหมุนเวียน/การใช้สุทธิ, Stock Value Change, สัดส่วนมูลค่าตามเครื่อง และ Item Turnover Rate ใช้ข้อมูลงวดและตัวกรองของรายงาน กดสินค้า/เครื่องเพื่อดูรายละเอียดในรายงาน ตัวกรองย่อยของ Stock Value Change แยกจาก Dashboard และรีเซ็ตเครื่อง/Supplier เมื่อแสดงรายงานชุดใหม่
